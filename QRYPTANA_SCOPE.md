# Qryptana Scope

Qryptana is the private communication pillar of the GoAnon ecosystem.

The goal of Qryptana is to provide privacy-first communication with reduced dependency on phone numbers, email identity, app stores, public user IDs, and mandatory push-notification infrastructure.

Qryptana is currently a downstream fork derived from SimpleX Chat.

## Current focus

The first Qryptana milestone is intentionally conservative:

- Keep the upstream SimpleX structure intact.
- Preserve license notices and attribution.
- Add Qryptana-specific documentation.
- Apply safe visible branding changes only after the repo still builds.
- Focus first on self-hosted relay/server infrastructure.
- Treat mobile store distribution as out of scope for the initial Qryptana release.

## Privacy positioning

Qryptana is designed around the following principles:

- No phone-number-first identity.
- No email-based identity requirement.
- No public user ID as the main discovery model.
- Invite-based communication.
- Store-free distribution direction where possible.
- Less convenience in exchange for less platform dependency and less identity exposure.

## Non-goals for the first milestone

The first milestone does not aim to:

- Create a new cryptographic protocol.
- Replace the SimpleX protocol design.
- Remove iOS or Android source trees blindly.
- Claim official affiliation with SimpleX.
- Ship native iOS or Android Qryptana releases.
- Overpromise anonymity or perfect security.

## Release target status

Initial Qryptana release targets are still being evaluated.

For now, iOS and Android code may remain in the repository as upstream reference material, but they are not Qryptana release targets unless explicitly documented later.

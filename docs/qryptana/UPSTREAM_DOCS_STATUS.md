# Upstream Documentation Status

This repository is currently a downstream fork derived from SimpleX Chat.

Many documentation files in this repository are retained from the upstream SimpleX Chat project for technical reference, attribution, and AGPL transparency.

These upstream documentation files may contain:

- SimpleX project links;
- SimpleX download links;
- SimpleX donation links;
- SimpleX team/contact information;
- SimpleX translation instructions;
- SimpleX server documentation;
- SimpleX protocol documentation;
- SimpleX branding references.

Unless a document is explicitly marked as Qryptana-specific, it should be treated as upstream reference material.

Qryptana-specific product identity is established in the repository-level
scope, attribution, and relationship documents. The retained upstream README
section in `README.md` is explicitly labeled as reference material and does not
define Qryptana releases or product commitments.

## Rule

Do not present upstream SimpleX documentation as Qryptana documentation without reviewing and adapting it first.

Do not use upstream SimpleX download links, donation links, team links, logos, or public release claims as Qryptana release material.
